Repository containing code from my PhD at the University of Tasmania, Hobart (2021-2025).

My thesis 'The Importance of Finescale Processes in the Southern Ocean' is available here: https://doi.org/10.13140/RG.2.2.34482.26566

Research papers using this code have been published in the Journal of Physical Oceanography are available on ResearchGate (https://www.researchgate.net/profile/Maya-Jakes) or on the journal website.
